# 네이버 카페 하네스 (검사 목록)

`npm run cafe:check` 가 아래 항목을 모두 검사합니다. 푸시 전 검사(`verify:fast`)에도 들어 있어서, 오류가 있으면 푸시가 막힙니다.
규칙 코드는 `cafe/scripts/lib/rules.mjs`, 금지·주의 표현 목록은 홈페이지와 함께 쓰는 `scripts/lib/adRules.mjs` 한 곳에 있습니다.
✖ 오류는 고쳐야 통과하고, ⚠ 경고는 사람이 확인합니다.

## A. 카페 설정 (`cafe.config.json`)
| 코드 | 검사 | 수준 | 이유 |
|---|---|---|---|
| A1 | 카페명 후보 20자 이내, 추천 1개 | ✖ | 검색 결과에서 잘리지 않게 |
| A2 | 카페 소개 200자 이내, 핵심 키워드 포함 | ✖ / ⚠ | 검색 요약·가입 결정 |
| A3 | 필수 영역(공지·상품·질문·자유·후기·상담) 게시판 존재 | ✖ | 구조 누락 방지 |
| A4 | 게시판 이름 중복 없음 | ✖ | 헷갈림 방지 |
| A5 | 쓰기·읽기 권한이 실제 등급 이름 | ✖ | 설정 오타 방지 |
| A6 | 후기 게시판은 운영자 작성 금지(`operatorWrite:false`) | ✖ | 고객을 가장한 광고 방지 |
| A7 | 상담 게시판은 링크 형식 | ✖ | 카페 안에서 연락처 수집 금지(개인정보) |
| A8 | 제휴 입점 메뉴는 비공개로 시작 | ✖ | 소속 규정·특별이익 확인 전 공개 금지 |
| A9 | 등급 조건이 위로 갈수록 같거나 높음 | ✖ | 등업 논리 오류 방지 |
| A10 | 등급 혜택에 금전·경품·할인 금지 | ✖ | 보험 모집 관련 특별이익 소지 |
| A11 | 글 아래 필수 고지 4종 존재 | ✖ | 운영자 표시·공식 아님·보험료 조건·민원 창구 |

## 자동으로 못 거르는 것 (사람이 확인)
- 다른 아이디로 글·댓글 쓰기, 여러 계정 돌리기 — 하지 않습니다. (네이버 이용약관 위반, 고객 기만)
- 회원님 후기를 운영자가 고쳐 쓰기 — 하지 않습니다.
- 상품 정보가 바뀌었는지 — 상품요약서 개정 때 `products.data.json` 과 원고를 함께 고칩니다.
