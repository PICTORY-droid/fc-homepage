밤늦게 앱으로 보험료를 내거나 대출을 받을 수 있는지 궁금하셨죠?
우체국보험 공식 자주하는 질문(FAQ) 답변을 바탕으로 쉽게 풀어 볼게요.

## 한 줄로 답하면

조회, 보험지급, 환급금대출은 24시간 되고, 보험료 실시간 납부는 05:00~23:30이에요.

## 자세히 알아볼게요

| 서비스 | 이용시간 |
| --- | --- |
| 보험조회·선납 등 주요거래 | 24시간 |
| 실시간 보험료 납부 | 05:00~23:30 |
| 보험청약철회 | 05:00~22:00 (토·일요일, 공휴일 불가) |
| 보험가입하기 | 06:00~23:00 |
| 환급금대출(당·타행) | 24시간 |
| 환급금대출상환(당행) | 24시간 |
| 환급금대출상환(타행) | 05:00~23:30 |
| 보험지급(당·타행) | 24시간 |
| 갱신거절 신청·취소 | 24시간 |

## 꼭 확인하세요

- 시스템 점검 같은 일이 생기면 서비스 시작 시간이 조금 늦어질 수 있어요.
- 내 계약에 맞는 정확한 내용은 우체국보험 고객센터(1599-0100)나 가까운 우체국에서 확인해 주세요.

## 같은 분류의 다른 질문

- 카카오페이 인증서, 우체국보험 앱에 어떻게 등록하나요?
- 금융인증서 비밀번호를 잊어버렸어요
- 금융인증서, 어디서 발급받나요?

## 문의할 곳

- 우체국보험 고객센터 1599-0100 (상담사 연결 평일 09:00~18:00)
- 가까운 우체국 금융창구 (평일 09:00~16:30)
- 스마트보험(우체국보험 앱) · 우체국보험 홈페이지

## 쉽게 말하면

조회와 대출, 보험금 받기는 언제든 되고, 보험료 내기는 밤 11시 30분까지예요.
