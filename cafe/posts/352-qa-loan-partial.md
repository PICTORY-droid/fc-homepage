대출을 한꺼번에 다 갚기는 부담되시죠? 일부만 갚을 수도 있어요.
우체국보험 공식 자주하는 질문(FAQ) 답변을 바탕으로 쉽게 풀어 볼게요.

## 한 줄로 답하면

네, 원금이나 이자를 일부만 갚을 수 있어요.

## 자세히 알아볼게요

1. 스마트보험
   - 원금부분상환: 전체메뉴(오른쪽 위 ≡) → 대출/상환 → 대출상환신청 → 환급금대출상환 → 원금상환 → 증서번호 선택·금액 입력(기존 대출금이 자동으로 들어가니 갚을 금액으로 고쳐 적기) → 계좌인증 → 본인인증
   - 이자부분상환: 같은 경로 → 이자부분상환 → 증서번호 선택·금액 입력 → 계좌정보 입력 → 계좌인증 → 본인인증
2. 우체국보험 홈페이지: 대출/상환 → 대출상환신청 → 환급금대출상환
3. 우체국 방문(평일 09:00~16:30): 계약자 본인 신분증
4. 고객센터(평일 09:00~18:00): 1599-0100 → 0번 → 1번

## 꼭 확인하세요

- 원금상환 화면에는 전체 대출금이 먼저 들어가 있어요. 갚을 금액으로 꼭 바꿔 적어 주세요.
- 내 계약에 맞는 정확한 내용은 우체국보험 고객센터(1599-0100)나 가까운 우체국에서 확인해 주세요.

## 같은 분류의 다른 질문

- 앱·홈페이지 환급금대출 신청 방법과 조건
- 앱·홈페이지 환급금대출 한도, 하루 얼마까지?
- 실효된 보험도 환급금대출 받을 수 있나요?

## 문의할 곳

- 우체국보험 고객센터 1599-0100 (상담사 연결 평일 09:00~18:00)
- 가까운 우체국 금융창구 (평일 09:00~16:30)
- 스마트보험(우체국보험 앱) · 우체국보험 홈페이지

## 쉽게 말하면

앱에서 갚을 금액만 바꿔 적으면 일부만 갚을 수 있어요.
