통신사 PASS 앱을 쓰고 계시다면 우체국보험 앱도 PASS로 로그인할 수 있어요.
우체국보험 공식 자주하는 질문(FAQ) 답변을 바탕으로 쉽게 풀어 볼게요.

## 한 줄로 답하면

PASS 앱에서 인증서를 발급한 뒤 우체국보험 앱 로그인 화면에서 PASS인증을 고르면 돼요.

## 자세히 알아볼게요

1. PASS 인증 발급: PASS 앱 → 메인 화면 → 인증서
2. 등록·이용: 우체국보험 앱 → 로그인 화면 → PASS인증

## 꼭 확인하세요

- PASS 인증으로는 로그인, 보험금 청구, 조회 서비스만 쓸 수 있어요.
- 내 계약에 맞는 정확한 내용은 우체국보험 고객센터(1599-0100)나 가까운 우체국에서 확인해 주세요.

## 같은 분류의 다른 질문

- 카카오페이 인증 메시지가 안 와요
- 스마트보험 가입 마지막 단계에서 카카오페이 인증이 안 돼요
- 다른 은행 공동인증서로 우체국보험 앱을 쓸 수 있나요?

## 문의할 곳

- 우체국보험 고객센터 1599-0100 (상담사 연결 평일 09:00~18:00)
- 가까운 우체국 금융창구 (평일 09:00~16:30)
- 스마트보험(우체국보험 앱) · 우체국보험 홈페이지

## 쉽게 말하면

PASS 인증서를 만들어 두면 우체국보험 앱에 바로 들어갈 수 있어요.
