치아·정기·상해 노트 25편이에요 🚘
오늘부터는 상해보험 이야기예요. 첫 상품은 교통재해를 집중해서 보장하는 우체국안전벨트보험이에요. 우체국안전벨트보험 상품요약서(2025년 4월 판)로 정리했어요.

## 이런 점이 특징이에요

- 가입나이가 많거나 적거나 상관없이 보험료가 같아요.
- 교통재해 사망과 장해를 크게 보장해요.
- 교통재해로 인한 입원, 수술, 골절, 외모수술, 깁스치료까지 치료비를 함께 보장해요.
- 주5일 근무제와 레저문화 확산에 맞춰 휴일 교통재해 사망을 더 강화했다고 안내해요.

## 가입 조건

| 항목 | 내용 |
| --- | --- |
| 보험종류 | 순수보장형 |
| 보험기간 | 20년 만기 |
| 가입나이 | 만15~70세 |
| 납입 | 20년납, 월납 |
| 가입금액 | 1,000만원 고정(기존 500만원 가입자는 500만원 가능) |
| 건강진단 | 없음 |

## 순수보장형이라는 뜻

교통재해가 아닌 원인으로 사망하면 그때의 계약자적립액을 드리는데, 상품요약서는 순수보장형이라 계약자적립액이 없거나 아주 적다고 안내해요.

## 쉽게 말하면

안전벨트보험은 '차와 관련된 사고만 콕 집어 크게 지켜 주는 보험'이에요. 다음 편에서 휴일과 평일 보장이 어떻게 다른지 볼게요.
