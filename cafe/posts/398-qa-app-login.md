우체국보험 앱(스마트보험)은 로그인 방법이 여러 가지예요. 편한 걸 고르시면 돼요.
우체국보험 공식 자주하는 질문(FAQ) 답변을 바탕으로 쉽게 풀어 볼게요.

## 한 줄로 답하면

금융인증서, 공동인증서, 카카오페이, 개인인증번호, 지문(얼굴), 패턴, PASS, 휴대폰 인증으로 로그인할 수 있어요.

## 자세히 알아볼게요

| 방법 | 한 줄 설명 |
| --- | --- |
| 금융인증서 | 금융결제원 클라우드에 보관, 우체국·타은행 앱이나 우체국예금 홈페이지 인증센터에서 발급 |
| 공동인증서 | 발급 후 PC에 저장된 인증서를 가져오기 |
| 카카오페이 인증 | 카카오톡에서 발급 후 이용 |
| 개인인증번호 | 6자리 숫자로 간편 로그인 |
| 지문(얼굴)인증 | 기기에 등록된 지문·얼굴로 인증 |
| 패턴인증 | 간편인증 등록 때 정한 패턴 |
| PASS 인증 | PASS 앱에서 발급, 로그인·보험금청구·조회 |
| 휴대폰 인증 | 문자 6자리로 로그인·보험금청구·조회 |

## 꼭 확인하세요

- 간편인증은 개인인증번호를 먼저 등록해야 쓸 수 있어요(전체메뉴 ≡ → 인증센터 → 간편인증 → 개인인증번호 등록).
- 간편인증 이용 기기: 안드로이드 6.0 이상, iOS 11.0 이상, 지문·얼굴인증을 지원하는 스마트폰
- 휴대폰을 바꾸거나 앱을 다시 깔면 다시 등록해야 해요.
- 내 계약에 맞는 정확한 내용은 우체국보험 고객센터(1599-0100)나 가까운 우체국에서 확인해 주세요.

## 같은 분류의 다른 질문

- 우체국보험 앱 개인인증번호가 사라졌어요
- 간편인증 등록 방법, 개인인증번호·지문·패턴
- 우체국보험 앱 PASS 인증, 어떻게 쓰나요?

## 문의할 곳

- 우체국보험 고객센터 1599-0100 (상담사 연결 평일 09:00~18:00)
- 가까운 우체국 금융창구 (평일 09:00~16:30)
- 스마트보험(우체국보험 앱) · 우체국보험 홈페이지

## 쉽게 말하면

처음엔 개인인증번호를 등록해 두면, 그다음부터는 6자리 숫자나 지문으로 쉽게 들어갈 수 있어요.
