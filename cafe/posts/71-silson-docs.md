실손 노트 13편이에요 🧾
실손은 서류만 잘 챙기면 청구가 어렵지 않아요. 우체국보험 공식 '자주하는 질문'의 서류 안내 그대로예요.

## 입원했을 때

- 진단서 또는 입퇴원확인서(병명 또는 병명코드, 입원기간 기재)
- 입퇴원 진료비계산서 영수증
- 입퇴원 진료비세부내역서
- 퇴원할 때 약을 처방받았다면: 의사처방전(환자보관용), 약제비 영수증(약국 발급)
- 보험금을 받을 분(수익자)의 신분증, 예금계좌번호

## 통원했을 때(외래 + 처방)

- 병명 확인 서류(진단서, 소견서, 진료확인서, 처방전, 차트 중 병명이나 병명코드가 적힌 것)
- 날짜별 진료비계산서 영수증
- 날짜별 진료비세부내역서(비급여가 있을 때)
- 의사처방전(환자보관용), 약제비 영수증(약국 발급)
- 수익자 신분증, 예금계좌번호

## 30만원 이하라면 더 간단해요

같은 병명으로 외래와 처방을 합쳐 30만원 이하라면, 병명 확인 서류를 생략하고 보험금청구서에 병명이나 병명코드를 직접 적으면 돼요.

## 진료비세부내역서가 뭐예요?

입원(통원) 기간 동안 날짜별로 어떤 약을 먹었는지, 어떤 주사를 맞았는지, 어떤 수술과 검사를 받았는지 자세히 보여 주는 병원 서류예요.

## 원본이 꼭 필요할까요?

원본이 원칙이지만, 1,000만원 이하 청구는 사본으로 낼 수 있어요. 심사하면서 서류를 더 요청할 수 있어요.

## 쉽게 말하면

병원에서 나올 때 "실손 청구용으로 영수증이랑 세부내역서 주세요"라고 한마디만 해 두세요. 다시 병원에 가는 번거로움이 사라져요.
