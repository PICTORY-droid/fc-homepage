어린이·엄마 노트 36편이에요 📱
부담 없이 시작하고 싶은 분께 맞는 상품이에요. 상품요약서는 '1만 원'으로 자녀 건강종합보장과 미래자금(적립금액)을 준다고 소개해요. 우체국 온라인어린이보험 상품요약서(2025년 4월 판)로 정리했어요.

## 가입 조건

| 항목 | 내용 |
| --- | --- |
| 가입나이 | 0~15세(임신 확인된 태아 포함) |
| 보험기간 | 30세 만기, 전기납, 월납 |
| 가입금액 | 1,000만원(고정) |
| 선천이상특약Ⅱ | 임신 23주 이내 태아에 고정으로 붙어요(3년) |

## 주요 보장 (1,000만원 기준)

| 보장 | 금액 |
| --- | --- |
| 암 진단 | 계약일부터 1년 미만 1,500만원, 1년 이상 3,000만원 |
| 소액암 진단 | 1년 미만 150만원, 1년 이상 300만원(각 최초 1회) |
| 소아암 진단 | 1년 미만 1,000만원, 1년 이상 2,000만원 |
| 재해장해 | 5,000만원 × 장해지급률 |
| 입원(4일 이상) | 3일 넘는 하루당 2만원 |
| 수술(1~5종) | 10만원~500만원 |
| 재해골절(치아파절 제외) / 깁스 / 화상 | 20만원 / 10만원 / 20만원 |
| 식중독 입원(4일 이상) | 3일 넘는 하루당 2만원 |
| 만기 | 적립금액 |

## 알아 둘 점

- 소아암 진단 때는 암진단보험금을 더해 줘요. 1년 이상이면 2,000만원 + 3,000만원 = 5,000만원이에요(전에 암진단보험금을 받았다면 더하지 않아요).
- 계약일에 태아였다면 1년 미만 감액을 적용하지 않아요.

## 쉽게 말하면

온라인어린이보험은 '작게 시작하는 아이 첫 보험 + 미래자금 저금통'이에요. 보장을 더 넓히고 싶다면 New든든한자녀지킴이보험과 비교해 보세요.
