보험 관리 노트 4편이에요 🎧
고객센터에 전화했는데 어느 번호를 눌러야 할지 헷갈리셨죠? 우체국보험 홈페이지 '고객센터 이용안내'로 정리했어요.

## 업무별 상담원 연결 코드 (1599-0100, 042-336-6898)

| 코드 | 상담 업무 |
| --- | --- |
| 01 | 환급금 대출 |
| 02 | 보험료 납입·자동이체·증명서, 고객정보 변경 |
| 03 | 수술·입원·실손보험금 |
| 04 | 연금·보험실효부활·계약사항 |
| 05 | 해약·만기·배당금·휴면보험금 |

상담시간은 평일 09:00~18:00이에요. ARS 안내에서는 '0'을 누른 뒤 업무 번호를 누르는 방식(예: 환급금 대출 상담은 0+1)으로 안내해요.

## 상담원이 도와주는 일

고객센터 안내에는 가입 문의, 대출과 세제, 계약사항, 생존보험금, 사고보험금, 불편사항, 폰뱅킹(ARS)과 인터넷 거래 문의, 인터넷 게시판 답변 등이 적혀 있어요. 인증서나 보안 프로그램 문의는 고객센터 이용안내 화면에 따로 안내된 연락처를 확인해 주세요.

## 알아 두면 좋아요

ARS 안내에는 본인이 아닌 경우 상담에 제한이 있을 수 있다고 적혀 있어요. 가족 보험을 문의할 때는 계약자 본인이 전화하는 것이 좋아요.

## 쉽게 말하면

'돈 빌리기 1, 납입·증명서 2, 병원비 3, 연금·부활 4, 해약·만기 5'로 외워 두면 연결이 빨라요.
