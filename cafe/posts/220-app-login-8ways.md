앱 청구 노트 2편이에요 🔑
앱을 쓰려면 먼저 로그인이죠. 우체국보험 앱에는 로그인 방법이 8가지나 있어요. 우체국보험 공식 '자주하는 질문' 안내로 정리했어요.

## 로그인 방법 한눈에

| 방법 | 이런 거예요 |
| --- | --- |
| 금융인증서 | 금융결제원 클라우드에 보관하는 인증서 |
| 공동인증서 | 발급 후 PC의 인증서를 앱으로 가져와서 사용 |
| 카카오페이 인증 | 카카오톡에서 발급한 간편인증 |
| 개인인증번호 | 직접 정한 6자리 숫자 |
| 지문인증(얼굴인증) | 휴대폰에 등록된 지문·얼굴 정보 |
| 패턴인증 | 간편인증 등록 때 정한 패턴 |
| PASS 인증 | 통신3사가 만든 간편인증 |
| 휴대폰 인증 | 문자로 받은 6자리 숫자 |

## 이용 가능한 휴대폰

간편인증은 안드로이드 6.0 이상, iOS(아이폰) 11.0 이상, 지문 또는 얼굴인증을 지원하는 스마트폰에서 쓸 수 있다고 안내해요.

## 어떤 걸 고를까요?

- 처음이라면 카카오페이 인증이나 금융인증서처럼 발급이 간단한 방법이 편해요.
- 자주 쓴다면 개인인증번호를 등록한 뒤 지문이나 패턴을 더해 두면 빨라요.
