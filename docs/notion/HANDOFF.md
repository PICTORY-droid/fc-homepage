# 양식노트(노션) 인수인계 문서

새 채팅에서 이 파일을 먼저 읽고 이어서 작업하세요. (저장소: PICTORY-droid/fc-homepage, 브랜치 feat/game → main)

## 1. 목적
- 우체국보험 FC 홈페이지(https://fc-homepage.vercel.app)로 유입을 늘리기 위한 노션 사이트 "양식노트" 제작.
- 노션 글 작성은 Claude가 모두 담당, 사용자는 "웹에 게시(Publish to web)" 버튼만 직접 누름.
- 사용자 원래 목표: 중복 없는 글 500개 이상. Claude 권고: 1차 약 40페이지 → 2주 트래픽 확인 → 확장. 유사도 검사 필수.

## 2. 사용자 정보/규칙
- 초보 개발자, 한국어, 한 번에 한 단계씩, 전체 파일 교체 방식 선호.
- "경남 김해" 문구 절대 금지.
- 글에 보험 권유/보장 표현 금지, 이력서·자기소개서에는 CTA 금지, 광고 심의번호(reviewNo)는 비워둠.
- 확인되지 않은 주장 금지(사실기반, 모르는 것은 "미확인"으로 표시).
- 노션 홈/글 본문에는 '우체국', '보험', '연락처' 단어를 쓰지 않는다(보험 광고 규제 회피, 무료 양식 콘텐츠로만 구성).
- 비밀번호/계정 정보는 채팅에 절대 공유하지 않음.

## 3. 디자인 톤앤매너
- 색: 주황 #FF883A(포인트), 배경 #FFF6EE → #FFE6D2 → #FFDAC1, 글자 #333, 칩/버튼 글자 #C4540A.
- 말투: "~해요" 체.
- 커버 이미지 7종: public/notion/cover-{home,ppt,excel,word,season,guide,request}.jpg (1500×600), 생성 스크립트 scripts/fun/notion/make_covers.mjs.
- 노션 커버는 가장자리가 잘리므로 글자는 세로 가운데 띠 안에 둠.
- 홈 구성: 커버 → 📂 아이콘 → 제목 "양식노트 · 무료 PPT·엑셀·워드 양식 900종+" → 부제 → 주황 메뉴 칩 6개 → 콜아웃 → 3열 갤러리(실제 양식 썸네일).

## 4. 카테고리 6개
PPT 템플릿 / 엑셀 양식 / 워드·인쇄물 / 계절별 모음 / 사용법 가이드 / 새 양식·요청

## 5. FC 홈페이지 연결 방식
- 글마다 FC 홈페이지 링크 1개, 글마다 다른 utm_campaign.
- 예: https://fc-homepage.vercel.app/fun/ppt-pro?utm_source=notion&utm_medium=blog&utm_campaign=bday_ppt
- 사이트는 utm_source/medium/campaign을 sessionStorage로 기록(track.ts).
- 양식 사용/상업 이용 조건은 사이트의 이용 안내를 확인한 뒤에만 글에 쓴다(미확인 상태에서 단정 금지).

## 6. 다음 작업 순서
1. 새 채팅에서 Notion 커넥터가 켜져 있는지 확인(+ 메뉴 → 커넥터).
2. 테스트 페이지 5개 생성 → 속도와 이미지 삽입 방식 확인.
3. 1차 약 40페이지: 홈, 메뉴 6개, 가이드, 첫 글 5개.
4. 글 간 유사도 검사 → 겹치는 글 수정.
5. 사용자에게 "웹에 게시"할 페이지 목록 안내.
6. 2주 트래픽(utm_campaign별) 확인 후 최대 약 500개로 확장.
- 노션 API는 비즈니스 플랜 외 분당 약 180회 제한 → 배치 간격 조절.
- 노션 Sites 커스터마이징 제한, "Built with Notion" 표시는 커스텀 도메인에서만 제거 가능.

## 7. 미해결 사항
- Vercel에 RESEND_API_KEY, RETENTION_MAIL_TO 설정 여부 확인(템플릿 요청 메일).
- 보험 광고 심의 주체는 미확인 → 사용자가 소속 지사/담당 부서에 확인.
- 네이버 블로그 연동(첫 "무료 양식" 글 등)은 별도 작업.
- 참고: 네이버 블로그 쓰기 API 종료, 티스토리 오픈 API 종료 → 노션이 자동 작성 가능한 현실적 대안.

## 8. 보험 글 (별도 노션 사이트로 분리)
- 우체국보험 관련 글은 양식노트와 **완전히 다른 최상위 페이지(별도 공개 URL)** 로 만든다. 양식노트 본문에는 보험 단어를 쓰지 않는다는 규칙(2번)을 유지하기 위함.
- 양식노트 ↔ 보험 사이트 사이에 서로 링크하지 않는다(보험 광고 규제 범위가 양식노트로 번지는 것 방지).
- 이름/배너는 새로 정한다(가칭 "보험노트"). 색·말투는 FC 홈페이지 톤(2·3번)을 따르되 커버는 보험용으로 별도 제작.
- 카테고리 안(사용자 확정 전): 우체국보험 이해하기 / 보험 용어 쉽게 / 보장 점검 방법 / 가입 전 체크리스트 / 자주 묻는 질문 / 소식·제도 안내
- 작성 원칙: 정보 제공형만. 가입 권유·보장 단정·타사 비교 우위·수익 보장 표현 금지. 판매 가능 상품 범위 확인(postal-fc-homepage 메모 참고). 수치·제도는 공식 출처 확인 후 기재, 미확인은 "미확인" 표시.
- 연락처(전화·카톡·이메일)는 글 본문에 넣지 않고 FC 홈페이지 링크로만 연결(연락처 포함 글은 업무광고로 볼 수 있다는 2021년 기사 근거, 미확정).
- 게시 전 필수: 광고 심의 주체/절차 확인(미확인 → 사용자가 소속 지사/담당 부서에 문의), 심의번호가 나오면 reviewNo에 반영.
- 순서: 양식노트 1차 완료 후, 보험 사이트는 5페이지 샘플 → 사용자 검토 → 심의 확인 → 확대.
- 결정(사용자 위임): 같은 노션 계정 안에서 최상위 페이지 2개(양식노트 / 보험노트)로 분리하고 각각 따로 "웹에 게시". 별도 계정은 만들지 않음. 공개 페이지에 작성자 정보가 어디까지 노출되는지는 미확인 → 게시 후 시크릿 창에서 확인.

## 9. 이력서·자기소개서 반영 (2026-10-20)
- 사이트: 포지션 30개 × 양식 10종 × (이력서·자기소개서) = Word 600개. 근거는 scripts/fun/docx/guide_data.py 주석(고용24·NCS·STAR·JSON Resume).
- 양식노트 홈 제목을 "… 양식 2,000종+"로 고치고, 메뉴에 "이력서·자기소개서 양식 모아보기" 허브를 추가했다.
- 블로그 주제에 "이력서", "자기소개서" 추가. 초안 7편(번호 4~10) 작성, 발행 상태는 모두 "초안"(사용자 검수 후 게시).
- CTA 규칙: 이력서·자기소개서 글에는 버튼·강조 상자(callout) 대신 글 끝의 일반 문장 링크 1개만 둔다. 링크마다 utm_campaign 이 다르다(blog_004~010, menu_forms).
- 노션 본문에는 '보험'·'우체국'·'연락처' 단어를 쓰지 않으므로 "보험·금융 영업" 포지션은 허브에서 "금융 영업"으로 적었다.
