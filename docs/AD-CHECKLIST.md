# 광고 문구 점검 목록

홈페이지에 새 문구·이미지를 넣기 전에 아래를 확인하세요. (공식 심의 기준은 아니며, 심의 전에 스스로 걸러내기 위한 목록입니다.)

## 자동 검사 (`npm run check`, 빌드 때 자동 실행)
- 금지 표현이 있으면 빌드가 실패합니다: 최고, 1위, 전액, 100%, 무조건, 확정수익, 원금보장, 수익률, 업계 최 …
- 주의 표현이 있으면 경고가 나옵니다(빌드는 통과): 보장합니다, 확실히, 반드시 받, 사은품, 경품, 특별 혜택, 절대

## 직접 확인
1. **비교·우열**: 다른 상품·타사와 우열을 단정하는 표현이 없는가? (비교 화면은 사실 정보만)
2. **수치·조건**: 보험료·보장금액을 쓸 때 가입 조건(나이·성별·기간)을 함께 적었는가?
3. **혜택 강조**: 세제 혜택·할인은 조건과 한계를 함께 적었는가? (세금 문구는 세무 전문가 확인 안내)
4. **기준일·출처**: 상품 정보에 기준일과 출처(상품요약서·고시)가 표시되는가?
5. **e마크 상품**: 온라인·콜센터 전용(e마크) 상품이 들어가지 않았는가? (`productsMeta.eMarkVerified`)
6. **판매중지 상품**: 판매가 끝난 상품이 남아 있지 않은가?
7. **사진·로고**: 본인 사진과 승인받은 로고만 사용했는가?
8. **개인정보**: 수집 항목·목적·보유 기간·문의처가 개인정보처리방침과 같은가?
9. **심의번호**: 광고 심의를 받았다면 `site.reviewNo` 를 입력했는가?
10. **상담 약속**: "상담만으로 가입되지 않습니다" 등 지킬 수 있는 약속만 적었는가?
